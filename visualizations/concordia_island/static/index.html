READING THE REPLAY

A record, brought to life.

This local viewer reads your saved Concordia Island output. It does not run a simulation or make model calls.

  • Mind & action shows the component text, prompt transcripts, action, and Game Master resolution saved in the log. It does not expose hidden model reasoning.
  • GM context shows the locations recorded for the selected resolution. Tick snapshot shows the separate location-history record.
  • Transitions between locations are illustrative. The run does not record exact walking paths.
  • Async events appear in saved log order. This is not a reconstruction of exact concurrent execution timing. Displayed ticks are grouped from the recorded simulation-clock labels.
  • Memories show the final saved memory bank. Persona data is matched by resident name from local generated populations, when available.
